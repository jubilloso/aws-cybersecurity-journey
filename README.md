# 🛡️ AWS Cybersecurity & Linux Journey

Practical labs, security scripts, cloud configurations, and study documentation from my **AWS - Cybersecurity Bootcamp (DIO)** and **Computer Science** degree.

## 🎯 Goals
- Build a solid foundation in **Linux administration, networking, and system security**.
- Master **AWS Cloud Security** services (IAM, GuardDuty, KMS, Shared Responsibility Model).
- Practice **Ethical Hacking & Pentesting** concepts (OSINT, Nmap, Metasploit) in authorized lab environments.
- Develop an **AI Security Agent** capable of identifying and mitigating code vulnerabilities.

## 📂 Repository Structure
- `01-artificial-intelligence/` — Prompt engineering templates and AI security workflows.
- `02-linux-security/` — Bash scripts, user/permission management (`chmod`, `chown`), and SSH hardening.
- `03-cybersecurity-fundamentals/` — Networking notes, threat modeling, and Kali Linux labs.
- `04-aws-security/` — IAM policies (JSON), GuardDuty threat detection, and KMS key management.
- `05-ethical-hacking/` — OSINT methodologies and Nmap network scanning write-ups.
- `06-vulnerability-exploitation/` — Lab write-ups on vulnerability analysis and mitigation.
- `07-final-project/` — AI-powered vulnerability scanner and remediation agent.

## 💻 Environment
- **OS:** Linux Mint
- **Tools:** Git, Bash, Python, AWS CLI, Nmap
